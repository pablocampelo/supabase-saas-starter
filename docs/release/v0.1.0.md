# DaysNotWeeks v0.1.0

Scope 2.0 repository release candidate.

The code is distributed by Git tag, not operated as a permanent hosted SaaS. Clone the repository, install from the frozen lockfile, configure your own Supabase/Auth/Google/SMTP/Stripe/Vercel integrations, apply migrations and replace the Example domain.

The permanent GitHub Actions workflow checks install, lint, typecheck, unit tests, build, clean database reset, RLS tests, generated types, and browser E2E.

Hosted release verification exercised registration, confirmation, password recovery, Google OAuth returning to Dashboard, paid Stripe test-mode Checkout, webhook processing and Pro entitlement. Adaptability was tested by replacing Example with Projects on a disposable branch; see closed PR #8. Each buyer must validate their own providers and deployment as described in docs/SETUP.md and docs/runbooks/BILLING.md.

Release tags identify the canonical product version. Local and hosted QA credentials are not included or distributed.
